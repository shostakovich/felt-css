Example

A stat tile is a card whose body carries .stat: a small uppercase .stat-label above a big .stat-value. Values use tabular figures, so numbers that update in place don't jitter. Color the card with a .text-bg-* helper and lay the tiles out with the grid.

Sizing

The value is 1.75rem by default. On small tiles, such as two to a row on a phone, scale it down with a font size utility like .fs-4.

Long labels

Labels hyphenate instead of overflowing a narrow tile. Hyphenation needs the page's lang, and browsers without a dictionary for it (Chromium on Linux) or all-caps English words don't hyphenate, so add soft hyphens (&shy;) to long compounds. .text-break on the label breaks anywhere as a last resort.

Semantic markup

.stat, .stat-label and .stat-value reset their margins without specificity, so they work on any element and .col.stat keeps the row's gutter. A description list ties each label to its value for assistive technologies, and extra lines like a trend fit underneath.
