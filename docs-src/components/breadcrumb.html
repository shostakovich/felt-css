Dividers

Dividers are automatically added in CSS through ::before and content. Change them with the custom property --felt-breadcrumb-divider, set on the breadcrumb or any parent.

Bootstrap calls this property --bs-breadcrumb-divider; felt-css uses --felt-breadcrumb-divider without the prefix.

It’s also possible to use an embedded SVG icon.

Inlined SVG requires properly escaped characters. Some reserved characters, such as <, > and #, must be URL-encoded or escaped. Read Kevin Weber’s explanations on CodePen for more info.

Accessibility

Since breadcrumbs provide a navigation, it’s a good idea to add a meaningful label such as aria-label="breadcrumb" to describe the type of navigation provided in the <nav> element, as well as applying an aria-current="page" to the last item of the set to indicate that it represents the current page.

For more information, see the ARIA Authoring Practices Guide breadcrumb pattern.

CSS

Variables

Breadcrumbs are built on local CSS variables, like Bootstrap's: .breadcrumb declares them and you can set them on any breadcrumb. The divider, --felt-breadcrumb-divider, isn't declared: set it on the breadcrumb or any parent (see dividers).
