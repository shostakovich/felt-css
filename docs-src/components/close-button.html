Example

Provide an option to dismiss or close a component with .btn-close. The icon is drawn in currentColor, so it follows the text color of its parent. Be sure to include text for screen readers, as we’ve done with aria-label.

Disabled state

Disabled close buttons change their opacity. We’ve also applied pointer-events: none to prevent hover and active states from triggering.

Dark variant

Add data-bs-theme="dark" to the .btn-close, or to its parent element, to get a close button for dark surfaces.

Bootstrap's deprecated .btn-close-white still works as well; it simply sets the color to white.
