How it works

Offcanvas is a sidebar component that can be toggled via JavaScript to appear from the left, right, top, or bottom edge of the viewport. Buttons or anchors are used as triggers that are attached to specific elements you toggle, and data attributes are used to invoke Bootstrap's JavaScript.

  • Offcanvas shares some of the same JavaScript code as modals. Conceptually, they are quite similar, but they are separate plugins.
  • When shown, offcanvas includes a default backdrop that can be clicked to hide the offcanvas.
  • Similar to modals, only one offcanvas can be shown at a time.

Heads up! Given how CSS handles animations, you cannot use margin or translate on an .offcanvas element. Instead, use the class as an independent wrapping element.

Dark offcanvas

To match an offcanvas to a dark context like a dark navbar, set data-bs-theme="dark" on it (or on a parent wrapper). Everything inside follows, including the close button and dropdowns, so felt-css needs no .btn-close-white or .dropdown-menu-dark.

Responsive

Bootstrap's responsive offcanvas classes (.offcanvas-sm, .offcanvas-md, .offcanvas-lg, …), which show the contents in place above a breakpoint, aren't part of felt-css. An .offcanvas is always an overlay.

Placement

There's no default placement for offcanvas components, so you must add one of the modifier classes below.

  • .offcanvas-start places offcanvas on the left of the viewport (shown above)
  • .offcanvas-end places offcanvas on the right of the viewport
  • .offcanvas-top places offcanvas on the top of the viewport
  • .offcanvas-bottom places offcanvas on the bottom of the viewport

Accessibility

Since the offcanvas panel is conceptually a modal dialog, be sure to add aria-labelledby="..."—referencing the offcanvas title—to .offcanvas. Note that you don't need to add role="dialog" since Bootstrap's JavaScript already adds it.

JavaScript behavior

felt-css is CSS only; showing and hiding come from Bootstrap's offcanvas plugin, which adds .showing, .show and .hiding while the sheet slides in and out. Add data-bs-toggle="offcanvas" and a data-bs-target or href to a trigger, and data-bs-dismiss="offcanvas" to a close button inside.

An offcanvas with .show in its markup is opened by Bootstrap's JavaScript on page load, backdrop and all. The static examples on this page are drawn by the docs without it.

Options (backdrop, keyboard, scroll), methods (show, hide, toggle, dispose, getInstance, getOrCreateInstance) and events (show.bs.offcanvas, shown.bs.offcanvas, hide.bs.offcanvas, hidden.bs.offcanvas, hidePrevented.bs.offcanvas) work exactly as described in Bootstrap's offcanvas documentation.

const bsOffcanvas = new bootstrap.Offcanvas('#myOffcanvas') bsOffcanvas.show()
