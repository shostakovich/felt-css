How it works

The accordion uses collapse internally to make it collapsible. felt-css also supports a variant built on <details> that needs no JavaScript; see Without JavaScript.

The animation effect of this component is dependent on the prefers-reduced-motion media query.

Without JavaScript

A felt-css extra: build the accordion from <details class="accordion-item"> elements with a <summary class="accordion-button">. The browser opens and closes them by itself, so no JavaScript is needed. Add the open attribute to show an item by default.

Please read the collapse accessibility section for more information. The <details> variant gets its keyboard support and state announcements from the browser.

Usage

The collapse plugin utilizes a few classes to handle the heavy lifting:

  • .collapse hides the content
  • .collapse.show shows the content
  • .collapsing is added when the transition starts, and removed when it finishes

Via data attributes

Just add data-bs-toggle="collapse" and a data-bs-target to the element to automatically assign control of one or more collapsible elements. The data-bs-target attribute accepts a CSS selector to apply the collapse to. Be sure to add the class collapse to the collapsible element. If you’d like it to default open, add the additional class show.

To add accordion group management to a collapsible area, add the data attribute data-bs-parent="#selector".

Via JavaScript

Enable manually with:

const accordionCollapseElementList = document.querySelectorAll('#myAccordion .collapse') const accordionCollapseList = [...accordionCollapseElementList].map(accordionCollapseEl => new bootstrap.Collapse(accordionCollapseEl))

JavaScript behavior

felt-css is CSS only; opening and closing comes from Bootstrap’s collapse plugin. Options (parent, toggle), methods (show, hide, toggle, dispose, getOrCreateInstance) and events (show.bs.collapse, shown.bs.collapse, hide.bs.collapse, hidden.bs.collapse) work exactly as described in Bootstrap’s accordion documentation.

CSS

Variables

Accordions are built on local CSS variables, like Bootstrap's: .accordion declares them and you can set them on any accordion; .accordion-flush sets the background to transparent. The icon is a mask painted in the button's text color, so any single-color icon (an SVG data URI, for example) takes the colors of the closed and the open button.
