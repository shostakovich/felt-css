Overview

Create custom <input type="range"> controls with .form-range. The track (the background) and thumb (the value) are both styled to appear the same across browsers.

In the felt look, the track is a groove pressed into the felt and the thumb is a small felt patch with a cast shadow.

Filled track

Unlike Bootstrap, felt-css can fill the track from the left up to the thumb. CSS can't read an input's value, so the filled part comes from the --felt-form-range-fill custom property (default 0%, i.e. no fill). Set it inline for a static value:

To follow the thumb while it's dragged, update --felt-form-range-fill from JavaScript. This works for any min, max and step:

for (const range of document.querySelectorAll('.form-range')) { const update = () => { const min = +range.min || 0 const max = range.max === '' ? 100 : +range.max range.style.setProperty('--felt-form-range-fill', `${(range.value - min) / (max - min) * 100}%`) } range.addEventListener('input', update) update() }

The ranges below this point on this page use exactly that script.

Thumb colour

The thumb and the filled part take their colour from --felt-form-range-thumb-bg (default: primary), set on the input or on any parent. A neutral thumb suits a slider whose track already carries the meaning.

Disabled

Add the disabled boolean attribute on an input to give it a grayed out appearance, remove pointer events, and prevent focusing.

Min and max

Range inputs have implicit values for min and max—0 and 100, respectively. You may specify new values for those using the min and max attributes.

Steps

By default, range inputs "snap" to integer values. To change this, you can specify a step value. In the example below, we double the number of steps by using step="0.5".

Output value

The value of the range input can be shown using the output element and a bit of JavaScript.

const rangeInput = document.getElementById('range4') const rangeOutput = document.getElementById('rangeValue') rangeOutput.textContent = rangeInput.value rangeInput.addEventListener('input', () => { rangeOutput.textContent = rangeInput.value })
