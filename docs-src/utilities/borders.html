Opacity

border-{color} utilities use CSS variables. This allows for real-time color changes and dynamic alpha transparency changes.

How it works

Consider the default .border-success utility.

.border-success { --felt-border-opacity: 1; border-color: color-mix(in srgb, var(--felt-success) calc(var(--felt-border-opacity) * 100%), transparent) !important; }

The color is faded with color-mix() by a second CSS variable, --felt-border-opacity, for the alpha transparency (with a default value 1 thanks to a local CSS variable). The local CSS variable inside each .border-* class avoids inheritance issues so nested instances of the utilities don't automatically have a modified alpha transparency.

Radius

Add classes to an element to easily round its corners.

Sizes

Use the scaling classes for larger or smaller rounded corners. Sizes range from 0 to 5 including circle and pill. They use the radius tokens --felt-radius-sm, --felt-radius, --felt-radius-lg, --felt-radius-xl and --felt-radius-xxl, which are a little rounder in the felt look.

Every side (top, end, bottom, start) comes in every size: .rounded-{side} and .rounded-{side}-{0|1|2|3|4|5|circle|pill}.
