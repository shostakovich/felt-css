Text alignment

Easily realign text to components with text alignment classes. For start, end, and center alignment, responsive classes are available that use the same viewport width breakpoints as the grid system (sm, md and lg).

Note that we don't provide utility classes for justified text. While, aesthetically, justified text might look more appealing, it does make word-spacing more random and therefore harder to read.

Word break

Prevent long strings of text from breaking your components' layout by using .text-break to set overflow-wrap: break-word and word-break: break-word. The deprecated word-break: break-word avoids issues with flex containers.

Font size

Quickly change the font-size of text. While the heading classes (e.g., .h1–.h6) apply font-size, font-weight, and line-height, these utilities only apply font-size. As the number increases, their size decreases. felt-css is made for apps, so its scale is more compact than Bootstrap's: from 2rem (.fs-1) down to .875rem (.fs-6).
