Examples

Quickly add or remove a shadow with the box-shadow utility classes. Includes support for .shadow-none and three default sizes, which use the matching custom properties --shadow-sm, --shadow and --shadow-lg. Shadows are a little stronger in dark mode, so they still read on a dark page.

Unlike in Bootstrap, many components already carry a shadow of their own (cards, list groups, dropdowns, modals, toasts). .shadow-none removes it.
