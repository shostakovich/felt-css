Accessibility tip: Using color to add meaning only provides a visual indication, which will not be conveyed to users of assistive technologies like screen readers. Please ensure the meaning is obvious from the content itself (e.g., the visible text with a sufficient color contrast) or is included through alternative means, such as additional text hidden with the .visually-hidden class.

Background color

Similar to the contextual text color classes, set the background of an element to any contextual class. Background utilities do not set color, so in some cases you'll want to use .text-* color utilities, or the .text-bg-* helpers that set both.

Unlike in Bootstrap, the .bg-* utilities of the theme colors respond to color modes: they are light-dark() pairs. .bg-light and .bg-dark keep their tone like Bootstrap's, so .bg-light .text-dark and .bg-dark .text-light stay readable in both modes.

In the felt look the solid theme fills are cut from saturated felt (.bg-light from cream felt, in both modes), and .bg-body* and .bg-*-subtle from the same cream (or charcoal) felt as the page. A fill made see-through with .bg-opacity-* is a tint instead: the felt underneath shows through it.

Inside a sewn piece (a card, a list group, a modal, an offcanvas), .bg-body-secondary and .bg-body-tertiary mark a well, e.g. the details of a selected row:

In the felt look such a well is a pocket: the felt is pressed in along its edge and held by a fine stitch. Its padding and size don't change.

Background gradient

By adding a .bg-gradient class, a linear gradient is added as background image to the backgrounds. This gradient starts with a semi-transparent white which fades out to the bottom. In the felt look it keeps the felt texture and swells like a patch instead.

Do you need a gradient in your custom CSS? Just add background-image: var(--gradient);.

Opacity

background-color utilities use CSS variables. This allows for real-time color changes and dynamic alpha transparency changes.

How it works

Consider the default .bg-success utility.

.bg-success { --bg-opacity: 1; background-color: color-mix(in srgb, var(--success) calc(var(--bg-opacity) * 100%), transparent) !important; }

The theme colors are light-dark() values rather than RGB triplets, so instead of Bootstrap's rgba() the utility fades the color with color-mix(), using a second CSS variable, --bg-opacity, for the alpha transparency (with a default value 1 thanks to a local CSS variable). The local CSS variable inside each .bg-* class avoids inheritance issues so nested instances of the utilities don't automatically have a modified alpha transparency.
