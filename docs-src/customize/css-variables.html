Overriding

All tokens live on :root inside @layer tokens. Any unlayered rule of yours wins over them, so overriding is just redefining:

:root { --felt-font: "Atkinson Hyperlegible", system-ui, sans-serif; --felt-radius: 6px; --felt-container-max: 1200px; }

Tokens can also be overridden on any element for that part of the page, like Bootstrap's component variables:

Felt

The felt look has its own tokens on :root[data-look="felt"]: the felt textures (--felt-texture, --felt-texture-light, --felt-texture-dark and their -size), the sheet everything light is cut from (--felt-texture-sheet, --felt-texture-sheet-blend), edge and shadow tones (--felt-patch-cut, --felt-patch-shadow-near, --felt-patch-shadow-far, …) and the seams (--_seam-img, --_seam-width, --felt-seam-inset, --felt-thread-filter, --felt-thread-strength). They are tuned together with the images that tools/build_assets.py generates; change the script rather than single values if you want a different stitch.

A cheap tweak that works: --felt-thread-strength (0–1) controls how strongly the thread shows on light felt, --felt-seam-inset how far in from the edge it is sewn.
