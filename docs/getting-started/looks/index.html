Getting started

Felt and clean

felt-css comes in two looks. One attribute switches between them, on the whole page or on a single element, and nothing moves when you do.

Switching looks#

Without any attribute you get the clean look: flat surfaces, hairline borders, Bootstrap-like. Add data-look="felt" to the <html> element and the same page is cut from wool felt and sewn together.

<html lang="en" data-look="felt">

Try it with the Felt / Clean switch at the top of this page: every example in these docs follows it.

Looks on single elements#

data-look works on any element, like data-bs-theme does for colour modes. The nearest one wins, and the element with the attribute counts too. A felt card on a clean page:

Neue Ausgabe

Cut from felt and sewn on, on a clean page.

<div class="card" data-look="felt" style="max-width: 22rem">
  <div class="card-header">Neue Ausgabe</div>
  <div class="card-body">
    <p class="card-text">Cut from felt and sewn on, on a clean page.</p>
    <button type="button" class="btn btn-primary">Save</button>
    <button type="button" class="btn btn-outline-secondary">Cancel</button>
  </div>
</div>

A single felt button among clean ones:

<button type="button" class="btn btn-primary" data-look="felt">Felt</button>
<button type="button" class="btn btn-primary">Clean</button>

And the other way round, a clean island in a felt page, for a dense table, a code block or a chart:

ItemAmount
Wool12,00 €
Thread3,50 €
 
<div class="card">
  <div class="card-body">
    <div class="table-responsive" data-look="clean">
      <table class="table table-sm table-striped mb-0">
        <thead><tr><th>Item</th><th>Amount</th></tr></thead>
        <tbody><tr><td>Wool</td><td>12,00 €</td></tr><tr><td>Thread</td><td>3,50 €</td></tr></tbody>
      </table>
    </div>
  </div>
</div>

Looks and colour modes combine freely: data-look="felt" data-bs-theme="dark" on one card gives a charcoal felt card on a light page. The page background stays whatever the page's own look is; a felt piece brings its own felt, and a see-through one (a flush list group or accordion) is cut from the sheet when it is the felt element itself.

Remembering the choice#

felt-css doesn't store anything itself. If you offer a switch, set the attribute before the first paint so the page doesn't flash, for example with a tiny inline script in the <head> — this is what these docs do:

<script>
  (() => {
    let look = null
    try { look = localStorage.getItem('look') } catch {}
    document.documentElement.dataset.look = look === 'clean' ? 'clean' : 'felt'
  })()
</script>

How the felt works#

Two felt recipes#

Saturated pieces (buttons, stat tiles, badges, the active pagination item) are patches: grey felt blended soft-light onto the colour, a soft cut edge and a cast shadow. Light surfaces (page, cards, alerts, list groups) are quiet felt: cream felt blended multiply, flat, at the same fibre scale. The grey felt is SVG noise; the cream felt is a photo. In dark mode the sheet is charcoal felt, also a photo.

Thread#

Seams are drawn 9-slice SVGs, taut stitches in a pressed groove, laid on with border-image; pills and square pieces get a seam that follows their edge, and round pieces one drawn for their size. They're tinted with mix-blend-mode: hard-light, so the thread is always a tone of the felt underneath: lighter on colour, a shade darker on cream. Dividers inside a piece (card headers, table rows, .vr, <hr>) are single rows of stitches. Border utilities are thread too: .border-{colour} dyes a piece's seam, and a bordered element without one gets a seam of its own (Firefox keeps the plain line).

Never moves#

The felt layer only changes colours, textures, shadows and seams — never padding, borders or fonts. Toggling the look doesn't shift a single pixel, so you can design in clean and switch to felt at the end, or let your users choose.

Opt-out friendly#

All felt rules sit in @layer felt, inside @scope ([data-look="felt"]) to ([data-look="clean"]), with the specificity of the component's own selector (.card stays one class). Unlayered CSS of yours always wins over the layer. To keep one element clean, give it data-look="clean"; to tune the felt, change its tokens (see Felt tokens).

Weight#

felt.css is about 38 KB gzipped. The felt textures and seams in img/ add about 26 KB and are only downloaded when the felt look is on.

Rebuilding the assets#

tools/build_assets.py draws the grey felt and the seam frames in img/ and their sizes into tools/feltgen/stitches.json; tools/build.py writes them into felt.css as tokens. Want longer stitches or rounder corners? Change LEN, PERIOD or SHAPES at the top of the script and run it again. After changing the grey felt's recipe (FELT), tools/calibrate_felt.py prints the base that keeps its brightness.

python3 tools/build_assets.py     # plain python3
python3 tools/build.py            # the seam sizes into felt.css
python3 tools/calibrate_felt.py   # needs Node with Playwright and ImageMagick

tools/combos.html shows every surface with every button, badge, border colour and seam radius, to check a change in both themes (?theme=dark).
