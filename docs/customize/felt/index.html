Tuning the felt#

Everything you see in the felt look — the fibres, the thickness of a piece, the thread — comes from the variables on this page. They only act in the felt look (their names carry a material word: texture, sheet, nap, wool, patch, groove, seam, thread or stitch), and like all variables they can be set for the whole page or for one part of it:

[data-look="felt"] {
  --felt-thread-strength: .9;        /* bolder seams */
  --felt-seam-inset: 7px;            /* sewn further in from the edge */
}
.card.quiet { --felt-patch-shadow: none; }   /* a card that lies flat */
<div class="d-flex flex-wrap gap-3">
  <button type="button" class="btn btn-primary">Default</button>
  <button type="button" class="btn btn-primary" style="--felt-thread-strength-patch: .95">Bold thread</button>
  <button type="button" class="btn btn-primary" style="--felt-thread-strength-patch: .2">Faint thread</button>
  <button type="button" class="btn btn-light border-danger">Dyed thread</button>
</div>

Switch to the felt look at the top of the page to see them; in the clean look they do nothing. Many values differ in dark mode, where the felt is charcoal.

The seam images are generated: tools/build_assets.py draws the stitches and grooves. For a different stitch length or rounder corners change the script rather than the sizes here.

Seams and thread#

The thread's colour is a filter on the drawn stitches, blended into the felt with hard-light: on light felt a darker tone of the felt, on coloured patches a lighter one. Border utilities dye it (.border-primary in the felt look is thread in the primary colour); for a colour of your own, use --felt-thread-filter and its variants.
