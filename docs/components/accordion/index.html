How it works#

The accordion uses collapse internally to make it collapsible. felt-css also supports a variant built on <details> that needs no JavaScript; see Without JavaScript.

The animation effect of this component is dependent on the prefers-reduced-motion media query.

Example#

Click the accordions below to expand/collapse the accordion content.

To render an accordion that’s expanded by default:

  • add the .show class on the .collapse element.
  • drop the .collapsed class from the .accordion-button element and set its aria-expanded attribute to true.

Bootstrap’s markup also puts an .accordion-collapse class on each collapsing element. felt-css doesn’t need it, but markup copied from Bootstrap works unchanged.

Without JavaScript#

A felt-css extra: build the accordion from <details class="accordion-item"> elements with a <summary class="accordion-button">. The browser opens and closes them by itself, so no JavaScript is needed. Add the open attribute to show an item by default.

Accordion Item #1
This is the first item’s accordion body. It is open by default because of the open attribute on its <details>.
Accordion Item #2
This is the second item’s accordion body. Click its summary and the browser opens it, no script involved.
Accordion Item #3
This is the third item’s accordion body. Several items can be open at the same time, like with “Always open”. 
<div class="accordion">
  <details class="accordion-item" open>
    <summary class="accordion-button">Accordion Item #1</summary>
    <div class="accordion-body">
      <strong>This is the first item’s accordion body.</strong> It is open by default because of the <code>open</code> attribute on its <code>&lt;details&gt;</code>.
    </div>
  </details>
  <details class="accordion-item">
    <summary class="accordion-button">Accordion Item #2</summary>
    <div class="accordion-body">
      <strong>This is the second item’s accordion body.</strong> Click its summary and the browser opens it, no script involved.
    </div>
  </details>
  <details class="accordion-item">
    <summary class="accordion-button">Accordion Item #3</summary>
    <div class="accordion-body">
      <strong>This is the third item’s accordion body.</strong> Several items can be open at the same time, like with “Always open”.
    </div>
  </details>
</div>

To let only one item be open at a time, give all <details> the same name attribute (supported by current browsers). The <details> variant opens without an animation and works with .accordion-flush, too.

Accordion Item #1
Only one of these items is open at a time.
Accordion Item #2
Opening this item closes the first one.
Accordion Item #3
And opening this one closes the second.
<div class="accordion">
  <details class="accordion-item" name="faq" open>
    <summary class="accordion-button">Accordion Item #1</summary>
    <div class="accordion-body">Only one of these items is open at a time.</div>
  </details>
  <details class="accordion-item" name="faq">
    <summary class="accordion-button">Accordion Item #2</summary>
    <div class="accordion-body">Opening this item closes the first one.</div>
  </details>
  <details class="accordion-item" name="faq">
    <summary class="accordion-button">Accordion Item #3</summary>
    <div class="accordion-body">And opening this one closes the second.</div>
  </details>
</div>

Accessibility#

Please read the collapse accessibility section for more information. The <details> variant gets its keyboard support and state announcements from the browser.

Usage#

The collapse plugin utilizes a few classes to handle the heavy lifting:

  • .collapse hides the content
  • .collapse.show shows the content
  • .collapsing is added when the transition starts, and removed when it finishes

Via data attributes#

Just add data-bs-toggle="collapse" and a data-bs-target to the element to automatically assign control of one or more collapsible elements. The data-bs-target attribute accepts a CSS selector to apply the collapse to. Be sure to add the class collapse to the collapsible element. If you’d like it to default open, add the additional class show.

To add accordion group management to a collapsible area, add the data attribute data-bs-parent="#selector".

Via JavaScript#

Enable manually with:

const accordionCollapseElementList = document.querySelectorAll('#myAccordion .collapse')
const accordionCollapseList = [...accordionCollapseElementList].map(accordionCollapseEl => new bootstrap.Collapse(accordionCollapseEl))

JavaScript behavior#

felt-css is CSS only; opening and closing comes from Bootstrap’s collapse plugin. Options (parent, toggle), methods (show, hide, toggle, dispose, getOrCreateInstance) and events (show.bs.collapse, shown.bs.collapse, hide.bs.collapse, hidden.bs.collapse) work exactly as described in Bootstrap’s accordion documentation.
