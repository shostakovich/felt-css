How it works#

  • The carousel is a slideshow for cycling through a series of content, built with CSS transforms and Bootstrap's JavaScript. It works with a series of images, text, or custom markup. It also includes support for previous/next controls and indicators.
  • For performance reasons, carousels must be manually initialized using the carousel constructor method. Without initialization, some of the event listeners (specifically, the events needed for touch/swipe support) will not be registered until a user has explicitly activated a control or indicator. The only exception are autoplaying carousels with the data-bs-ride="carousel" attribute, which are initialized automatically on page load. Don't initialize those again with the constructor.
  • Nested carousels are not supported. You should also be aware that carousels in general can often cause usability and accessibility challenges.
  • The slides move with a transition that felt-css turns off for visitors who ask for reduced motion (prefers-reduced-motion: reduce), like Bootstrap does.

Basic examples#

Here is a basic example of a carousel with three slides. Note the previous/next controls. We recommend using <button> elements, but you can also use <a> elements with role="button".

<div id="carouselExample" class="carousel slide">
  <div class="carousel-inner">
    <div class="carousel-item active">
      <div class="ratio ratio-21x9"><img src="../../../docs/sample-photo.webp" class="object-fit-cover" alt="A felt sun on a sunny windowsill"></div>
    </div>
    <div class="carousel-item">
      <div class="ratio ratio-21x9"><img src="../../../docs/banner.webp" class="object-fit-cover" alt="felt-css in blue felt letters, with patches around"></div>
    </div>
    <div class="carousel-item">
      <div class="ratio ratio-21x9"><img src="../../../docs/felt.webp" class="object-fit-cover" alt="Forms in the felt look"></div>
    </div>
  </div>
  <button class="carousel-control-prev" type="button" data-bs-target="#carouselExample" data-bs-slide="prev">
    <span class="carousel-control-prev-icon" aria-hidden="true"></span>
    <span class="visually-hidden">Previous</span>
  </button>
  <button class="carousel-control-next" type="button" data-bs-target="#carouselExample" data-bs-slide="next">
    <span class="carousel-control-next-icon" aria-hidden="true"></span>
    <span class="visually-hidden">Next</span>
  </button>
</div>

Carousels don't automatically normalize slide dimensions. As such, you may need to use additional utilities or custom styles to appropriately size content; the examples here put each image in a .ratio and crop it with .object-fit-cover. While carousels support previous/next controls and indicators, they're not explicitly required. Add and customize as you see fit.

You must add the .active class to one of the slides, otherwise the carousel will not be visible. Also be sure to set a unique id on the .carousel for optional controls, especially if you're using multiple carousels on a single page. Control and indicator elements must have a data-bs-target attribute (or href for links) that matches the id of the .carousel element. Keep the .slide class: Bootstrap's JavaScript only animates a carousel that has it.

In the felt look the slides are a photo lying on the felt, held by four little felt corners. The previous/next controls are small round patches of undyed wool, sewn on with a ring of stitches, and the indicators are a row of stitches across the photo; the current slide's is a patch. In dark mode, or with .carousel-dark, the patches are charcoal felt.

Autoplaying carousels#

You can make your carousels autoplay on page load by setting the ride option to carousel. Autoplaying carousels automatically pause while hovered with the mouse. This behavior can be controlled with the pause option. In browsers that support the Page Visibility API, the carousel will stop cycling when the webpage is not visible to the user (such as when the browser tab is inactive, or when the browser window is minimized).

For accessibility reasons, we recommend avoiding the use of autoplaying carousels. If your page does include an autoplaying carousel, we recommend providing an additional button or control to explicitly pause/stop the carousel. See WCAG 2.2 Success Criterion 2.2.2 Pause, Stop, Hide.

<div id="carouselExampleAutoplaying" class="carousel slide" data-bs-ride="carousel">
  <div class="carousel-inner">
    <div class="carousel-item active">
      <div class="ratio ratio-21x9"><img src="../../../docs/sample-photo.webp" class="object-fit-cover" alt="A felt sun on a sunny windowsill"></div>
    </div>
    <div class="carousel-item">
      <div class="ratio ratio-21x9"><img src="../../../docs/banner.webp" class="object-fit-cover" alt="felt-css in blue felt letters, with patches around"></div>
    </div>
    <div class="carousel-item">
      <div class="ratio ratio-21x9"><img src="../../../docs/felt.webp" class="object-fit-cover" alt="Forms in the felt look"></div>
    </div>
  </div>
  <button class="carousel-control-prev" type="button" data-bs-target="#carouselExampleAutoplaying" data-bs-slide="prev">
    <span class="carousel-control-prev-icon" aria-hidden="true"></span>
    <span class="visually-hidden">Previous</span>

Custom transition#

The transition duration of .carousel-item can be changed with custom styles; Bootstrap's JavaScript waits for whatever duration the CSS sets. If multiple transitions are applied, make sure the transform transition is defined first (e.g. transition: transform 2s ease, opacity .5s ease-out).

.carousel-item {
  transition-duration: 1.2s;
}

CSS#

Variables#

The carousel declares these on .carousel; .carousel-dark sets them to black. Bootstrap draws white icons and darkens them with --bs-carousel-control-icon-filter in dark mode; felt-css draws the icons in --felt-carousel-indicator-active-bg instead, so the filter is none and free for your own use.

TokenDefaultBootstrap
--felt-carousel-indicator-active-bglight-dark(#fff, #000)--bs-carousel-indicator-active-bg
--felt-carousel-caption-colorlight-dark(#fff, #000)--bs-carousel-caption-color
--felt-carousel-control-icon-filternone--bs-carousel-control-icon-filter

In the felt look the same variables colour the felt: --felt-carousel-indicator-active-bg is the colour of the control patches, the stitches and the current slide's patch (undyed wool, or charcoal felt in dark mode and with .carousel-dark), and --felt-carousel-caption-color the captions' ink.

Usage#

Via data attributes#

Use data attributes to easily control the position of the carousel. data-bs-slide accepts the keywords prev or next, which alters the slide position relative to its current position. Alternatively, use data-bs-slide-to to pass a raw slide index to the carousel data-bs-slide-to="2", which shifts the slide position to a particular index beginning with 0.

Via JavaScript#

felt-css is CSS only; the sliding comes from Bootstrap's carousel plugin. Call it manually with:

const carousel = new bootstrap.Carousel('#myCarousel', {
  interval: 2000,
  touch: false
})

Options (interval, keyboard, pause, ride, touch, wrap), methods (cycle, pause, prev, next, nextWhenVisible, to, dispose, getInstance, getOrCreateInstance) and events (slide.bs.carousel, slid.bs.carousel) work exactly as described in Bootstrap's carousel documentation.
