Examples#

Alerts are available for any length of text, as well as an optional close button. For proper styling, use one of the eight required contextual classes (e.g., .alert-success). For inline dismissal, use Bootstrap's alerts JavaScript plugin.

Alerts are pieces of light felt, tinted with their colour and sewn onto the page with a running stitch. Like in Bootstrap, alerts stay subtle; for a solid fill use .text-bg-*.

Additional content#

Alerts can also contain additional HTML elements like headings, paragraphs and dividers.

Well done!

Aww yeah, you successfully read this important alert message. This example text is going to run a bit longer so that you can see how spacing within an alert works with this kind of content.

Whenever you need to, be sure to use margin utilities to keep things nice and tidy.

<div class="alert alert-success" role="alert">
  <h4 class="alert-heading">Well done!</h4>
  <p>Aww yeah, you successfully read this important alert message. This example text is going to run a bit longer so that you can see how spacing within an alert works with this kind of content.</p>
  <hr>
  <p class="mb-0">Whenever you need to, be sure to use margin utilities to keep things nice and tidy.</p>
</div>

Dismissing#

Using Bootstrap's alert JavaScript plugin, it's possible to dismiss any alert inline. Here's how:

  • Be sure you've loaded Bootstrap's JavaScript.
  • Add a close button and the .alert-dismissible class, which adds extra padding to the right of the alert and positions the close button.
  • On the close button, add the data-bs-dismiss="alert" attribute, which triggers the JavaScript functionality.
  • To animate alerts when dismissing them, be sure to add the .fade and .show classes.
Holy guacamole! You should check in on some of those fields below. 
<div class="alert alert-warning alert-dismissible fade show" role="alert">
  <strong>Holy guacamole!</strong> You should check in on some of those fields below.
  <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
</div>

When an alert is dismissed, the element is completely removed from the page structure. If a keyboard user dismisses the alert using the close button, their focus will suddenly be lost. Listen for the closed.bs.alert event and move focus somewhere sensible.

JavaScript behavior#

felt-css is CSS only; dismissing comes from Bootstrap's alert plugin. Methods (close, dispose, getOrCreateInstance) and events (close.bs.alert, closed.bs.alert) work exactly as described in Bootstrap's alert documentation.

const alert = bootstrap.Alert.getOrCreateInstance('#myAlert')
alert.close()

Variables#

Alerts are built on local CSS variables, like Bootstrap's: .alert declares them (the defaults are the primary alert's), the .alert-* variants set the colours, and you can set them on any alert. Links (.alert-link) take the alert's text colour.

TokenDefaultBootstrap
--felt-alert-bgcolor-mix(in oklab, var(--felt-primary) 12%, var(--felt-surface))--bs-alert-bg
--felt-alert-padding-xvar(--felt-space-4)--bs-alert-padding-x
--felt-alert-padding-yvar(--felt-space-3)--bs-alert-padding-y
--felt-alert-margin-bottom0--bs-alert-margin-bottom
--felt-alert-colorvar(--felt-primary-emphasis)--bs-alert-color
--felt-alert-border-colorcolor-mix(in oklab, var(--felt-primary) 30%, var(--felt-surface))--bs-alert-border-color
--felt-alert-bordervar(--felt-border-width) solid var(--felt-alert-border-color)--bs-alert-border
--felt-alert-border-radiusvar(--felt-radius-lg)--bs-alert-border-radius
--felt-alert-link-colorvar(--felt-alert-color)--bs-alert-link-color

In the felt look an alert is a piece of felt dyed in its variant's colour, and --felt-alert-bg is that dye mixed into the light felt (the light and dark alerts have tones of their own). How much dye goes in is a felt-look token, set on the alert:
